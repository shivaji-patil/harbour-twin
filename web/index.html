How this was built

  1. Discover through STAC: NRCan HRDEM lidar and MRDEM, Copernicus GLO-30 and Sentinel-2 on Earth Search, Overture Maps buildings.
  2. Read only the window we need from COGs over HTTP range requests and GeoParquet through DuckDB. Nothing is bulk-downloaded.
  3. Align vertical datums with explicit PROJ pipelines: EGM2008, CGVD2013 (CGG2013a with the NAD83(CSRS) frame), WGS 84 for Cesium, and EGM96 for DTED.
  4. QC every DEM against lidar (bias, RMSE, NMAD, LE90, by slope) and gate it against product specs.
  5. Measure building heights from lidar (DSM − DTM), flag disagreements with Overture, and write OGC 3D Tiles 1.1 with per-building metadata.
  6. Integrate live feeds: AIS from aisstream.io, tides from CHS IWLS, weather from ECCC and Open-Meteo.
  7. Package for offline use: DTED Level 2 and a GeoPackage, all published as a STAC catalog.

Data: NRCan (OGL-Canada), Copernicus DEM © DLR/Airbus, Sentinel-2 (ESA Copernicus), Overture Maps (ODbL/CDLA), OpenStreetMap contributors, aisstream.io, DFO-CHS, ECCC, Open-Meteo, CARTO.
